That NAGGER Privacy Policy

Last updated: September 2, 2026
Privacy and support contact: that.nagger.app@gmail.com
General support information: That NAGGER Support

That NAGGER is designed to keep reminder data on the user's device and to avoid unnecessary collection, tracking, accounts, advertising identifiers, analytics, and advertising.

Information stored locally

That NAGGER stores Nags, schedules, notes, labels, History, Statistics inputs, notification settings, theme settings, app preferences, and other app configuration locally on the Android device.

Optional App Security PIN and biometric configuration is device-local. That NAGGER does not transmit the user's PIN or biometric data. Android performs biometric authentication through the operating system.

Optional device-calendar synchronization uses Android's Calendar Provider. That NAGGER reads available writable calendars and creates or updates selected Nag events on the device. Nag notes and labels are not exported to calendar events, and privacy settings are respected. If the user's calendar provider synchronizes its calendar to a cloud service, that synchronization is controlled by the calendar provider or account, not by That NAGGER.

Optional custom notification-sound files remain referenced through Android's Storage Access Framework and are not uploaded by That NAGGER.

Backups

That NAGGER disables Android automatic app-data backup for its own data. The app instead provides explicit user-controlled Backup & restore.

A user may choose a plain portable backup or a password-protected portable backup. Protected backups use AES-256-GCM with a key derived from the user's passphrase using PBKDF2-HMAC-SHA256. The passphrase is not stored in the backup. The user chooses where backup files are saved through Android's Storage Access Framework.

Feedback

The optional Send Feedback feature transmits only the information the user chooses to submit:

  • feedback category;
  • feedback message;
  • optional reply email address;
  • optional app version/build, Android version, and device manufacturer/model.

Feedback is sent over HTTPS to the That NAGGER feedback service hosted on Cloudflare and is then stored as a private development issue in GitHub. No advertising ID, Android ID, serial number, account identifier, or other persistent unique device identifier is intentionally collected by That NAGGER's feedback feature.

Cloudflare necessarily receives ordinary network connection information while handling the HTTPS request. The That NAGGER feedback Worker uses the connection IP only to derive a short-lived one-way hash for basic rate limiting. The raw IP address and rate-limit hash are not included in the private GitHub feedback issue.

Feedback and an optional reply email may be retained as long as reasonably useful for development, support, abuse prevention, or recordkeeping. A user may request deletion of a feedback submission through Send Feedback → Other or by emailing that.nagger.app@gmail.com and providing enough information to identify the submission.

Google Play purchases

The optional Small, Medium, and Large Thank You purchases are processed by Google Play Billing. That NAGGER receives the purchase state and token information needed to complete and consume the purchase and increments local Thank You counters after successful consumption. That NAGGER does not receive or store the user's payment-card details.

Thank You purchases do not unlock features, remove ads, create subscriptions, or change app functionality.

Information That NAGGER does not use

That NAGGER does not include third-party advertising, behavioral advertising, analytics SDKs, social tracking, or an app account system. It does not intentionally collect location, contacts, photos, microphone recordings, browsing history, advertising IDs, or persistent device fingerprints.

Permissions

That NAGGER may request Android permissions or special access for notifications, exact alarms, Calendar access, and biometric authentication when the user chooses functionality that requires them. Permission state is controlled by Android and can be changed in system settings.

Data retention and deletion

Because That NAGGER does not create user accounts or maintain a cloud copy of ordinary Nag data, uninstalling the app removes ordinary local app data subject to Android and device behavior. User-created backup files remain wherever the user chose to save them until the user deletes those files.

For feedback stored by the developer, request deletion through Send Feedback → Other or email that.nagger.app@gmail.com and provide enough information to identify the feedback submission.

Security

That NAGGER uses HTTPS for transmitted feedback, keeps ordinary reminder data local to the device, and uses Android platform mechanisms for permissions, biometric authentication, file access, and Google Play Billing. Password-protected backups use authenticated encryption as described above.

Changes to this policy

This policy may be updated when That NAGGER's features or data practices change. The current Google Play version should always link to a policy matching the behavior of that release.

Privacy contact

Privacy questions, support requests, and data-deletion inquiries may be sent to that.nagger.app@gmail.com.
